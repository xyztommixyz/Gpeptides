# Demo Labs (Beispielprojekt)

Dieses `site/` ist ein **Demo-Shop**, damit der Bauplan sofort lokal läuft. Beim Anlegen eines echten Shops
wird alles in `site/` ersetzt – siehe „Neues Projekt aus dem Bauplan“ in der `README.md` im Hauptordner.

- `site.json`: Name, Domain, Schalter (hier: Cases, Discord und Spin aus)
- `products.json`: drei Beispielprodukte
- `texts.json`, `case.json`: leer
- `deploy/`: Vorlagen mit `demo-labs.example`
